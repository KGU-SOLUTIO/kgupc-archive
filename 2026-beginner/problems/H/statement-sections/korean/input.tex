
첫 번째 줄에 기룡이가 시청을 시작하는 요일 $D$와 에피소드의 개수 $N$이 공백으로 구분되어 주어진다.  
$N$은 $1$ 이상 $1\,000\,000$ 이하의 정수이고, $D$는 \texttt{Mon}, \texttt{Tue}, \texttt{Wed}, \texttt{Thu}, \texttt{Fri}, \texttt{Sat}, \texttt{Sun} 중 하나이다.

두 번째 줄에 각 에피소드의 재생 시간 $t_1, t_2, \ldots, t_N$이 공백으로 구분되어 주어진다.

\begin{itemize}
    \item 각 재생 시간은 \texttt{MM:SS} 형식으로 주어진다.
    \item \texttt{MM}은 분을 나타내며, 두 자리 이상 세 자리 이하로 주어진다. 세 자리인 경우 첫 자리는 \texttt{0}이 아니다.
    \item \texttt{SS}는 초를 나타내며, \texttt{00} 이상 \texttt{59} 이하의 두 자리로 주어진다.
    \item 모든 에피소드의 재생 시간은 초 단위로 정확하게 주어진다.
    \item 각 에피소드의 재생 시간은 $1$초 이상이다.
\end{itemize}
