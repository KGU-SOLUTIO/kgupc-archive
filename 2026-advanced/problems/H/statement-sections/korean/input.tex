첫째 줄에 기룡이를 뺀 반 친구의 수 $N$과 지목 관계의 수 $M$이 공백을 사이에 두고 주어진다. 
친구들은 $1$번부터 $N$번까지 번호가 붙어 있다. ($2 \le N \le 100\,000$; $0 \le M \le 100\,000$)

둘째 줄부터 $M$개의 줄에 걸쳐 지목 관계가 주어진다. 
그중 $i$번째 줄에는 두 정수 $a_i$와 $b_i$가 공백을 사이에 두고 주어진다. 
이는 $a_i$번 친구가 $b_i$번 친구를 지목할 수 있다는 뜻이다. ($1 \le a_i,b_i \le N$; $a_i \ne b_i$)

같은 지목 관계가 두 번 이상 주어지지 않는다.
