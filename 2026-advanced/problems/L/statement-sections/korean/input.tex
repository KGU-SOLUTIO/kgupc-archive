첫째 줄에 기지와 거점을 합한 위치의 수 $N$, 그림자 밟기의 최대 이동 거리 $M$, 쿨타임 $K$가 공백을 사이에 두고 주어진다. $(2 \le N \le 17;\ 1 \le M \le 10\,000;\ 1 \le K \le 20)$

둘째 줄부터 $N$개의 줄에 걸쳐 $i$번 위치의 좌표 $x_i$, $y_i$와 점령에 필요한 시간 $o_i$가 공백을 사이에 두고 주어진다. $(-10\,000 \le x_i, y_i \le 10\,000;\ 0 \le o_i \le 10\,000)$

입력으로 주어지는 모든 수는 정수이다. $1$번 위치는 기지이며 $o_1=0$이다. 서로 다른 두 위치의 좌표는 같지 않다.
