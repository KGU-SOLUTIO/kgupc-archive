첫째 줄에 문제 후보의 수 $N$, 검수자 후보의 수 $M$, 운영진이 문제 하나 또는 검수자 한 명을 선택할 때마다 받는 고통 $C$가 공백을 사이에 두고 주어진다. ($1 \le N,M \le 200\,000$; $1 \le C \le 10^{12}$)

둘째 줄에 각 문제 후보의 티어를 나타내는 $N$개의 정수 $a_1,a_2,\cdots,a_N$이 공백을 사이에 두고 주어진다. ($1 \le a_i \le 10^8$)

셋째 줄에 각 검수자 후보의 티어를 나타내는 $M$개의 정수 $b_1,b_2,\cdots,b_M$이 공백을 사이에 두고 주어진다. ($1 \le b_j \le 10^8$)
