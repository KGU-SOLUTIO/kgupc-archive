
첫째 줄에 세 정수 $N,V,W$가 공백으로 구분되어 주어진다. $V,W$는 각각 볼록다각형 $P,Q$의 꼭짓점 개수이다.

다음 $V$개의 줄에 볼록다각형 $P$의 꼭짓점 좌표 $x_i,y_i$가 공백으로 구분되어 반시계 방향 순서로 주어진다.

다음 $W$개의 줄에 볼록다각형 $Q$의 꼭짓점 좌표 $x_i,y_i$가 공백으로 구분되어 반시계 방향 순서로 주어진다.

다음 조건을 만족한다.

\begin{itemize}
\item $4\le N\le 2^{18}$이며, $N$은 $2$의 거듭제곱이다.
\item $3\le V,W;V+W\le 10\,000$
\item $-10^8\le x_i,y_i\le 10^8$
\item 모든 꼭짓점의 좌표는 정수이다.
\item 두 다각형은 넓이가 양수인 볼록다각형이다.
\item 두 다각형 모두 원점 $(0,0)$을 내부에 포함한다.
\item 각 다각형에서 연속한 세 꼭짓점은 일직선 위에 있지 않다.
\end{itemize}
