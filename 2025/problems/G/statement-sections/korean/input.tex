첫째 줄에 지하철역을 포함한 학교의 모든 건물의 개수를 나타내는 정수 $n$이 주어진다. $(1 \le n \le 300\,000)$

둘째 줄부터 $n$개의 줄에 각 건물의 좌표를 뜻하는 두 정수 $x_i$, $y_i$가 공백으로 구분되어 주어진다. $(1 \le i \le n, -10^7 \le x_i, y_i \le 10^7)$

동일한 좌표가 여러 번 주어질 수 있다.
모든 점의 좌표가 같으면 무빙워크의 길이는 0이다.

모든 점이 한 직선 위에 놓이면 도시의 넓이는 0이다.
