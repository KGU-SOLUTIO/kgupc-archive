영어 공부를 하던 기룡이는 앞으로 공부해야 할 단어들을 사전 순으로 정렬한 후에 공부하고 싶어한다.

하지만 기존의 A-Z정렬에 싫증을 느낀 기룡이는 자신이 정한 순서대로 단어들을 정렬할 것이라고 다짐한다.

기룡이가 직접 정의한 알파벳 정렬 기준과 단어들이 주어지면 해당 단어들을 주어진 정렬 기준에 맞게 출력 해주는 프로그램을 작성하자. 만약 단어 A가 단어 B의 앞부분(접두사)과 완전히 같다면, 길이가 더 긴 B가 더 높은 우선 순위를 가진다. 예를 들어, 단어 "ab"와 "abc"의 경우, "ab"가 "abc"의 접두사이기 때문에 "abc"가 더 먼저 와야 한다.
