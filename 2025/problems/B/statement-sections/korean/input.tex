첫째 줄에 출입 기록의 개수 $N$이 주어진다. $(1 < N \le 1\,000)$
$N$은 짝수임이 보장된다.

둘째 줄부터 $N$개의 줄에 다음 정보가 공백으로 구분되어 주어진다.

\begin{enumerate}
    \item 기록 시각: 0 이상 1,440 이하의 정수이며, 분 단위로 주어진다.
    \item 입차/출차 여부: \texttt{IN}은 입차, \texttt{OUT}은 출차를 의미한다.
    \item 차량 번호: 알파벳 대문자 및 0에서 9까지의 숫자로 이루어진 다섯 글자의 문자열이다.
\end{enumerate}

기록은 시간순으로 주어진다.
각 차량의 입차 기록과 출차 기록은 각각 한 번씩 주어지며, 입차 시각은 출차 시각보다 작거나 같음이 보장된다.
