첫 줄에 출입 기록의 개수 $N$ $(1 < N \le 1,000)$이 주어진다. $N$은 짝수임이 보장된다.

두 번째 줄부터 N개의 줄에는 다음 정보가 띄어쓰기로 구분되어 주어진다.

1. 기록이 찍힌 시간: 0 이상 1,440 이하의 정수이다.

2. 입차/출차 여부: IN은 입차, OUT은 출차를 의미한다.

3. 차량 번호: 알파벳 대문자 및 0에서 9까지의 숫자로 이루어진 다섯 글자의 문자열이다.

기록은 시간 순으로 주어지며, 동일한 차량 번호에 대해 IN이 찍힌 시간이 항상 OUT보다 작거나 같음이 보장된다.
